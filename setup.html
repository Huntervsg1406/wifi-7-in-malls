The equipment and procedure used to conduct the WiFi 7 field investigation at Westfield Newmarket.

Setup Tutorial

  1. Choose a testing scenario and place the equipment at the predetermined testing location.
  2. Set up the ASUS WiFi 7 router, client devices and TP-Link WiFi 7 adapters.
  3. Ensure Kali Linux is configured correctly and the WiFi 7 adapter drivers are up to date.
  4. Connect the devices to the required WiFi network and frequency band.
  5. Configure the client and server devices for iperf3 testing.
  6. Use iperf3 to generate network traffic between the two client devices.
  7. Capture the wireless traffic using Wireshark.
  8. Record the throughput and RSSI measurements from the test.
  9. Store the results in the investigation dataset.
  10. Repeat the experiment for the required frequency bands and predetermined testing scenarios.

Monitoring Mode & iPerf3 Configuration

In order to collect data from the WiFi adapters, monitoring mode was configured so that RadioTap headers and RSSI could be read using Wireshark.

Monitoring Mode & Wireshark

Setup Configuration

Check the current network and channel:

iw dev wlan0 info

Set channel and frequency:

sudo iw dev wlan0mon set channel x
sudo iw dev wlan0mon set freq <frequency>

Get the router BSSID:

iw dev wlan0 link

Get the Kali device MAC:

ip link show wlan0

Get the target device MAC:

arp -n | grep <target-ip>

Enable Monitoring Mode

sudo reboot
sudo iw reg set NZ
iw dev

sudo airmon-ng check kill
sudo airmon-ng start wlan0

Wireshark Filters

Only traffic on the BSS:

wlan.bssid == aa:bb:cc:dd:ee:ff

Traffic between the two devices:

(wlan.sa == <your-kali-mac> && wlan.da == <target-mac>) ||
(wlan.sa == <target-mac> && wlan.da == <your-kali-mac>)

Client to server traffic:

wlan.sa == <Client-mac> && wlan.da == <Server-mac>

iPerf3 UDP traffic:

(wlan.bssid == aa:bb:cc:dd:ee:ff) && udp.port == 5201

iPerf3 Configuration

iPerf3 was used to generate network traffic between the client and server devices during testing.

Installation

sudo apt update
sudo apt install -y iperf3

Server (Receiver)

iperf -s

Client (Sender)

iperf3 <mode> <destination-ip> <udp-mode> <bandwidth> <duration> <interval>

Example UDP test:

iperf3 -c <server-ip> -u -b 10M -t 60 -i 1

Test Configuration

For all tests, the iPerf3 client was configured to send traffic for 60 seconds with intervals of 1 second.
