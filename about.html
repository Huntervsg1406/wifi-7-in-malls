About the Project

Exploring WiFi 7 performance in a real-world shopping mall environment.

WiFi 7 Mall Testing

This project aims to look at the performance of Wi-Fi 7 in a busy environment, specifically in a Westfield shopping mall. Wi-Fi 7 is a new version of Wi-Fi with improved speed, lower latency, and better support for a large number of devices compared to Wi-Fi 6. However, most of the current data on Wi-Fi 7 is based on controlled and theory testing, making it difficult for network planners to accurately get its performance in real-world places like shopping malls. This project addresses this gap by collecting real-world data in a busy/controlled environment and developing a tool to support future network planning.

The main objective of this project is to analyse Wi-Fi 7 link quality by measuring key performance factors such as throughput and received signal strength (RSS) in a shopping mall environment. Using the collected data, the team will identify suitable models and develop an online estimation tool that allows users to predict Wi-Fi performance in different mall scenarios. The span of the project includes setting up a Wi-Fi 7 test setup, carrying out field testing, analysing the data, and developing the estimation tool, with the focus being on a high-density retail environment.

The project will be done using the Waterfall method, which provides a clear approach to planning, research, testing, development, and final delivery. The project is divided into four main parts which include; planning, research and investigation, website development, and final presentation. This schedule will go across multiple weeks, making sure there are regular team meetings to make sure there is steady progress and everything is done on time.

There are some risks to this project, including possible technical issues with tools or equipment that we might have since we lack the experience with Wi-Fi 7, equipment availability, and potential scheduling issues due to everyone being busy on different days. These risks will be sorted through early planning, testing tools in advance and regular team meetings to monitor progress and resolve issues.

Project Aim

The aim of the project is to investigate how WiFi 7 performs within a high-density shopping mall environment and identify how network performance differs between frequency bands and testing locations.

The collected results can help provide insight into the performance and suitability of WiFi 7 for large indoor environments such as shopping malls.
